# Leaflet 图层对比控件

一个面向 Leaflet 的图层对比控件。本项目将在保持
[`leaflet-side-by-side`](https://github.com/digidem/leaflet-side-by-side)
现有参数、方法和事件兼容的基础上，提供更完整、可靠且易于维护的实现，
并作为公开包发布到 npm。

> 项目目前处于初始化阶段，插件的实现规范、包名和构建产物尚未最终确定。

## 项目目标

- 兼容原 `leaflet-side-by-side` 的初始化参数、公开方法与事件。
- 支持在分割线两侧直观对比 Leaflet 图层。
- 改善边界场景、图层生命周期和交互行为。
- 提供完善的 TypeScript 类型、自动化测试和示例。
- 在不破坏兼容性的前提下，为后续能力扩展保留清晰边界。

## 兼容性原则

原插件的公开 API 将作为本项目的兼容基线，包括：

- `L.control.sideBySide(leftLayers, rightLayers, options)` 工厂方法。
- `L.Control.SideBySide` 控件。
- 左右图层设置方法及控件生命周期方法。
- 原插件公开的选项和事件。

在实现规范确定前，不新增与原插件冲突的默认行为。若后续需要扩展 API，
扩展能力应保持可选，并在文档中明确说明与兼容 API 的关系。

## 当前阶段

当前仓库仅完成 Vite + TypeScript 项目初始化，尚不包含可用的插件实现。
接下来将重点确定：

- API 与事件的完整兼容清单。
- 图层类型、地图生命周期及异常场景的处理方式。
- DOM、触摸、鼠标和键盘交互规范。
- 包格式、浏览器兼容范围和发布策略。
- npm 包名、版本策略和发布流程。
- 单元测试、集成测试与示例页面结构。

## 发布说明

本项目计划作为公开 npm 包发布。当前 `package.json` 暂时沿用
`leaflet-side-by-side` 作为包名；该名称已被原插件占用，正式发布前需确认
现有包的发布权限，或改用新的包名（例如组织 scope 下的包名）。

入口文件、类型声明和 `exports` 配置将在插件构建规范确定后补充，避免当前
Vite 示例应用的构建产物被误认为可发布的库文件。

## 本地开发

要求 Node.js，并使用 pnpm 安装依赖：

```bash
pnpm install
pnpm dev
```

执行类型检查和生产构建：

```bash
pnpm build
```
